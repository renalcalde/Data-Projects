# 8 Week SQL Challenge

The [8 Week SQL Challenge](https://8weeksqlchallenge.com/) was created by [Data With Danny](https://www.linkedin.com/company/datawithdanny/home/) that consists of 8 real-world SQL case studies to help students jumpstart their data analytic careers and master their SQL skills.

Mainly being a self-taught analysts, I'm working through all 8 case studies to strengthen my skills and demonstrate my analytical abilities. This repo is a work in progress, and I'll add each case study as I complete it.
