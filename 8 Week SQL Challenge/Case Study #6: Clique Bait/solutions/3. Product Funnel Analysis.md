# 3. Product Funnel Analysis

Using a single SQL query - create a new output table which has the following details:

- How many times was each product viewed?
- How many times was each product added to cart?
- How many times was each product added to a cart but not purchased (abandoned)?
- How many times was each product purchased?

Additionally, create another table which further aggregates the data for the above points but this time for each product category instead of individual products.

Use your 2 new output tables - answer the following questions:

1. Which product had the most views, cart adds and purchases?
2. Which product was most likely to be abandoned?
3. Which product had the highest view to purchase percentage?
4. What is the average conversion rate from view to cart add?
5. What is the average conversion rate from cart add to purchase?

---

Before answering the questions, we must create our tables by doing the following steps:

1. Use SUM() + CASE to count the number of Page View event
2. Use the same logic as the first step, but filter for Add to Cart event instead

```SQL
SELECT
    e.visit_id,
    e.page_id,
    e.event_type,
    h.page_name,
    h.product_id,
    SUM(CASE WHEN event_type = 1 THEN 1 ELSE 0 END) AS viewed,
    SUM(CASE WHEN event_type = 2 THEN 1 ELSE 0 END) AS add_to_cart
FROM events e
INNER JOIN page_hierarchy h 
    ON e.page_id = h.page_id
GROUP BY e.visit_id, e.page_id, h.page_name, h.product_id, e.event_type
```

3. Create a purchase CTE that filters for unique visits who has a Purchase event
4. Use a CASE to act as a binary flag for every purchase when visit is not NULL
5. Combine both CTEs with a LEFT JOIN so all rows are kept from the `base_cte` and matches them to the `purchase_cte`

```SQL
WITH base_cte AS(
    SELECT
        e.visit_id,
        e.page_id,
        e.event_type,
        h.page_name,
        h.product_id,
        SUM(CASE WHEN event_type = 1 THEN 1 ELSE 0 END) AS viewed,
        SUM(CASE WHEN event_type = 2 THEN 1 ELSE 0 END) AS add_to_cart
    FROM events e
    INNER JOIN page_hierarchy h 
        ON e.page_id = h.page_id
    GROUP BY e.visit_id, e.page_id, h.page_name, h.product_id, e.event_type
),
purchased_cte AS(
    SELECT 
        DISTINCT visit_id
    FROM events
    WHERE event_type = 3
),
combine_cte AS(
    SELECT
        b.visit_id,
        b.page_id,
        b.event_type,
        b.page_name,
        b.product_id,
        b.viewed,
        b.add_to_cart,
        CASE WHEN p.visit_id IS NOT NULL THEN 1 ELSE 0 END AS purchase
    FROM base_cte b
    LEFT JOIN purchased_cte p
        ON b.visit_id = p.visit_id
)
```

6. Use SUM() + CASE to count the number of time a product was added to cart AND not purchased along with the number of times a product was added to cart AND purchased
7. GROUP BY the `product_id` and `product_name`
8. SELECT all required information and filter results so `product_id` is not NULL, then ORDER BY `product_id`

```SQL
WITH base_cte AS(
    SELECT
        e.visit_id,
        e.page_id,
        e.event_type,
        h.page_name,
        h.product_id,
        SUM(CASE WHEN event_type = 1 THEN 1 ELSE 0 END) AS viewed,
        SUM(CASE WHEN event_type = 2 THEN 1 ELSE 0 END) AS add_to_cart
    FROM events e
    INNER JOIN page_hierarchy h 
        ON e.page_id = h.page_id
    GROUP BY e.visit_id, e.page_id, h.page_name, h.product_id, e.event_type
),
purchased_cte AS(
    SELECT 
        DISTINCT visit_id
    FROM events
    WHERE event_type = 3
),
combine_cte AS(
    SELECT
        b.visit_id,
        b.page_id,
        b.event_type,
        b.page_name,
        b.product_id,
        b.viewed,
        b.add_to_cart,
        CASE WHEN p.visit_id IS NOT NULL THEN 1 ELSE 0 END AS purchase
    FROM base_cte b
    LEFT JOIN purchased_cte p
        ON b.visit_id = p.visit_id
),
info_cte AS(
    SELECT
        product_id,
        page_name AS product_name,
        SUM(viewed) AS viewed,
        SUM(add_to_cart) AS cart_added,
        SUM(CASE WHEN add_to_cart >= 1 AND purchase = 0 THEN 1 ELSE 0 END) AS abandoned,
        SUM(CASE WHEN add_to_cart >= 1 AND purchase >= 1 THEN 1 ELSE 0 END) AS purchased
    FROM combine_cte
    GROUP BY product_id, product_name
)
SELECT
    product_name,
    viewed,
    cart_added,
    abandoned,
    purchased
FROM info_cte
WHERE product_id IS NOT NULL
ORDER BY product_id;
```

**3. Which product had the highest view to purchase percentage?**

```SQL
SELECT 
    product_name,
    ROUND(MAX(purchased * 100.0 / viewed), 2) AS view_to_purchase_pct
FROM product_info
GROUP BY product_name
ORDER BY view_to_purchase_pct DESC;
```

**Result**:

<img width="391" height="258" alt="3" src="https://github.com/user-attachments/assets/12c32645-4305-43d9-819c-4027bae6fbbc" /><br>
- Lobster has the highest percentage of 48.74% from view to purchase, compared to Russian Caviar who has the lowest percentage of 44.59%. This suggests, people are viewing the product but something is turning them away from purchasing it, this can range from a high price to low demand for the item. Further investigation is needed to understand the low percentage for Russian Caviar.
