# 4. Campaigns Analysis

Generate a table that has 1 single row for every unique visit_id record and has the following columns:

- `user_id`
- `visit_id`
- `visit_start_time`: the earliest event_time for each visit
- `page_views`: count of page views for each visit
- `cart_adds`: count of product cart add events for each visit
- `purchase`: 1/0 flag if a purchase event exists for each visit
- `campaign_name`: map the visit to a campaign if the visit_start_time falls between the start_date and end_date
- `impression`: count of ad impressions for each visit
- `click`: count of ad clicks for each visit
- (Optional column) `cart_products`: a comma separated text value with products added to the cart sorted by the order they were added to the cart (hint: use the sequence_number)
  
Use the subsequent dataset to generate at least 5 insights for the Clique Bait team - bonus: prepare a single A4 infographic that the team can use for their management reporting sessions, be sure to emphasise the most important points from your findings.

Some ideas you might want to investigate further include:

- Identifying users who have received impressions during each campaign period and comparing each metric with other users who did not have an impression event
- Does clicking on an impression lead to higher purchase rates?
- What is the uplift in purchase rate when comparing users who click on a campaign impression versus users who do not receive an impression? What if we compare them with users who just an impression but do not click?
- What metrics can you use to quantify the success or failure of each campaign compared to eachother?

Before analyzing the data, we must create our table by doing the following steps:

1. JOIN `events` with `users` to get the `user_id` and `visit_id`
2. Use MAX() on `user_id` to avoid GROUP BY and MIN() on `event_time` to get the earliest time for each visit

```SQL
SELECT 
    MAX(u.user_id) AS user_id,
    e.visit_id,
    MIN(e.event_time) AS visit_start_time
FROM events e
INNER JOIN users u 
    ON e.cookie_id = u.cookie_id
GROUP BY e.visit_id;
```

3. Use SUM() + CASE to count for the following event types: views, cart adds, impression and click

```SQL
SELECT 
    MAX(u.user_id) AS user_id,
    e.visit_id,
    MIN(e.event_time) AS visit_start_time,
    SUM(CASE WHEN e.event_type = 1 THEN 1 ELSE 0 END) AS page_views,
    SUM(CASE WHEN e.event_type = 2 THEN 1 ELSE 0 END) AS cart_adds,
    SUM(CASE WHEN e.event_type = 4 THEN 1 ELSE 0 END) AS impression,
    SUM(CASE WHEN e.event_type = 5 THEN 1 ELSE 0 END) AS click
FROM events e
INNER JOIN users u 
    ON e.cookie_id = u.cookie_id
GROUP BY e.visit_id;
```

4. Use MAX() + CASE to create a binary flag for every purchase event

```SQL
SELECT 
    MAX(u.user_id) AS user_id,
    e.visit_id,
    MIN(e.event_time) AS visit_start_time,
    SUM(CASE WHEN e.event_type = 1 THEN 1 ELSE 0 END) AS page_views,
    SUM(CASE WHEN e.event_type = 2 THEN 1 ELSE 0 END) AS cart_adds,
    MAX(CASE WHEN e.event_type = 3 THEN 1 ELSE 0 END) AS purchase,
    SUM(CASE WHEN e.event_type = 4 THEN 1 ELSE 0 END) AS impression,
    SUM(CASE WHEN e.event_type = 5 THEN 1 ELSE 0 END) AS click
FROM events e
INNER JOIN users u 
    ON e.cookie_id = u.cookie_id
GROUP BY e.visit_id;
```

5. JOIN `campaign_identifier` on `event_time` BETWEEN `start_date` AND `end_date`
6. Wrap `campaign_name` in MAX() to avoid GROUP BY and COALESCE() to turn every NULL into 'No Campaign'

```SQL
SELECT 
    MAX(u.user_id) AS user_id,
    e.visit_id,
    MIN(e.event_time) AS visit_start_time,
    SUM(CASE WHEN e.event_type = 1 THEN 1 ELSE 0 END) AS page_views,
    SUM(CASE WHEN e.event_type = 2 THEN 1 ELSE 0 END) AS cart_adds,
    MAX(CASE WHEN e.event_type = 3 THEN 1 ELSE 0 END) AS purchase,
    COALESCE(MAX(c.campaign_name), 'No Campaign') AS campaign,
    SUM(CASE WHEN e.event_type = 4 THEN 1 ELSE 0 END) AS impression,
    SUM(CASE WHEN e.event_type = 5 THEN 1 ELSE 0 END) AS click
FROM events e
INNER JOIN users u 
    ON e.cookie_id = u.cookie_id
INNER JOIN campaign_identifier c
    ON e.event_time BETWEEN c.start_date AND c.end_date
GROUP BY e.visit_id;
```

7. JOIN `page_hierarchy` to get the `product_id`
8. Convert `product_id` from an INT into a TEXT
9. Use a STRING_AGG() to combine all `product_id` into a shopping cart sorted by the sequence number that the user interacted with them

```SQL
SELECT 
    MAX(u.user_id) AS user_id,
    e.visit_id,
    MIN(e.event_time) AS visit_start_time,
    SUM(CASE WHEN e.event_type = 1 THEN 1 ELSE 0 END) AS page_views,
    SUM(CASE WHEN e.event_type = 2 THEN 1 ELSE 0 END) AS cart_adds,
    MAX(CASE WHEN e.event_type = 3 THEN 1 ELSE 0 END) AS purchase,
    COALESCE(MAX(c.campaign_name), 'No Campaign') AS campaign,
    SUM(CASE WHEN e.event_type = 4 THEN 1 ELSE 0 END) AS impression,
    SUM(CASE WHEN e.event_type = 5 THEN 1 ELSE 0 END) AS click,
    STRING_AGG(p.product_id::TEXT, ', ' ORDER BY e.sequence_number) AS cart_products
FROM events e
INNER JOIN users u 
    ON e.cookie_id = u.cookie_id
INNER JOIN campaign_identifier c
    ON e.event_time BETWEEN c.start_date AND c.end_date
INNER JOIN page_hierarchy p 
    ON e.page_id = p.page_id 
GROUP BY e.visit_id
ORDER BY user_id, visit_start_time;
```

10. Create a new table called `campaign_info` with the new values

```SQL
DROP TABLE IF EXISTS campaign_info;

CREATE TABLE campaign_info AS 
SELECT 
    MAX(u.user_id) AS user_id,
    e.visit_id,
    MIN(e.event_time) AS visit_start_time,
    SUM(CASE WHEN e.event_type = 1 THEN 1 ELSE 0 END) AS page_views,
    SUM(CASE WHEN e.event_type = 2 THEN 1 ELSE 0 END) AS cart_adds,
    MAX(CASE WHEN e.event_type = 3 THEN 1 ELSE 0 END) AS purchase,
    COALESCE(MAX(c.campaign_name), 'No Campaign') AS campaign,
    SUM(CASE WHEN e.event_type = 4 THEN 1 ELSE 0 END) AS impression,
    SUM(CASE WHEN e.event_type = 5 THEN 1 ELSE 0 END) AS click,
    STRING_AGG(p.product_id::TEXT, ', ' ORDER BY e.sequence_number) AS cart_products
FROM events e
INNER JOIN users u 
    ON e.cookie_id = u.cookie_id
INNER JOIN campaign_identifier c
    ON e.event_time BETWEEN c.start_date AND c.end_date
INNER JOIN page_hierarchy p 
    ON e.page_id = p.page_id 
GROUP BY e.visit_id
ORDER BY user_id, visit_start_time;
```

**3. Does clicking on an impression lead to higher purchase rates?**

```SQL
WITH count_cte AS (
    SELECT
        COUNT(*) FILTER (WHERE impression = 1 AND click = 0) AS imp_no_click_visits,
        COUNT(*) FILTER (WHERE impression = 1 AND click = 0 AND purchase >= 1) AS imp_no_click_purchases,
        COUNT(*) FILTER (WHERE click = 1) AS click_visits,
        COUNT(*) FILTER (WHERE click = 1 AND purchase >= 1) AS click_purchases
    FROM campaign_info
),
rates_cte AS (
    SELECT
        (imp_no_click_purchases * 100.0 / imp_no_click_visits) AS imp_no_click_rate,
        (click_purchases * 100.0 / click_visits) AS click_rate
    FROM count_cte
)
SELECT
    ROUND(imp_no_click_rate, 2) AS no_click_rate,
    ROUND(click_rate, 2) AS click_rate,
    ROUND(click_rate - imp_no_click_rate, 2) AS uplift_pp
FROM rates_cte;
```

**Result**:

<img width="458" height="65" alt="2" src="https://github.com/user-attachments/assets/44e1cde6-3046-4b78-964c-ab6619a079f3" /><br>
- Yes, clicking on an impression has a higher purchase rate (89.65%) than those who didn't click (66.22%). Since our uplift percentage is positive (23.43%), it means that clickers purchased at a higher rate.
- However, this only shows that clicking is associated with a higher purchase rate and not that every click caused a purchase. This suggests, people who click were probably interested in the product to begin with.


**4. What is the uplift in purchase rate when comparing users who click on a campaign impression versus users who do not receive an impression? What if we compare them with users who just an impression but do not click?**

```SQL
WITH count_cte AS (
    SELECT
        -- no impression
        COUNT(*) FILTER (WHERE impression = 0) AS no_imp_visits,
        COUNT(*) FILTER (WHERE impression = 0 AND purchase >= 1) AS no_imp_purchases,

        -- impression w/ no click
        COUNT(*) FILTER (WHERE impression = 1 AND click = 0) AS imp_no_click_visits,
        COUNT(*) FILTER (WHERE impression = 1 AND click = 0 AND purchase >= 1) AS imp_no_click_purchases,

        -- impression w/ click
        COUNT(*) FILTER (WHERE click = 1) AS click_visits,
        COUNT(*) FILTER (WHERE click = 1 AND purchase >= 1) AS click_purchases
    FROM campaign_info
),
rates_cte AS (
    SELECT
        (no_imp_purchases * 100.0 / no_imp_visits) AS no_imp_rate,
        (imp_no_click_purchases * 100.0 / imp_no_click_visits) AS imp_no_click_rate,
        (click_purchases * 100.0 / click_visits) AS click_rate
    FROM count_cte
)
SELECT
    ROUND(no_imp_rate, 2) AS no_impression_rate,
    ROUND(imp_no_click_rate, 2) AS impression_no_click_rate,
    ROUND(click_rate, 2) AS click_rate,
    ROUND(imp_no_click_rate - no_imp_rate, 2) AS uplift_no_click_pp,
    ROUND(click_rate - no_imp_rate, 2) AS uplift_click_pp
FROM rates_cte;
```

        -- fish campaign

        SUM(CASE WHEN c.click = 1 AND i.campaign_id = 1 THEN 1 ELSE 0 END) AS f_click_count,

**8. What was the conversion rate from click to purchase for each campaign?**

```SQL
WITH campaign_cte AS(
SELECT
    -- fish campaign
    SUM(CASE WHEN c.impression = 1 AND c.click = 1 AND c.purchase >= 1 AND i.campaign_id = 1 THEN 1 ELSE 0 END) AS purchase_fish_campaign,
    SUM(CASE WHEN c.impression = 1 AND c.click = 1 AND i.campaign_id = 1 THEN 1 ELSE 0 END) AS fish_campaign,

    -- luxury campaign
    SUM(CASE WHEN c.impression = 1 AND c.click = 1 AND c.purchase >= 1 AND i.campaign_id = 2 THEN 1 ELSE 0 END) AS purchase_luxury_campaign,
    SUM(CASE WHEN c.impression = 1 AND c.click = 1 AND i.campaign_id = 2 THEN 1 ELSE 0 END) AS luxury_campaign,

    -- shellfish campaign
    SUM(CASE WHEN c.impression = 1 AND c.click = 1 AND c.purchase >= 1 AND i.campaign_id = 3 THEN 1 ELSE 0 END) AS purchase_shellfish_campaign,
    SUM(CASE WHEN c.impression = 1 AND c.click = 1 AND i.campaign_id = 3 THEN 1 ELSE 0 END) AS shellfish_campaign
FROM campaign_info c
INNER JOIN campaign_identifier i
    ON c.campaign = i.campaign_name
)
SELECT
    ROUND(SUM(purchase_fish_campaign * 100.0/ fish_campaign), 2) AS fish_campaign_conversion_rate,
    ROUND(SUM(purchase_luxury_campaign * 100.0/ luxury_campaign), 2) AS luxury_campaign_conversion_rate,
    ROUND(SUM(purchase_shellfish_campaign * 100.0/ shellfish_campaign), 2) AS shellfish_campaign_conversion_rate
FROM campaign_cte;
```
