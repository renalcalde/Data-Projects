**2. How many cookies does each user have on average?**
- Use COUNT() to get the total number of cookies, GROUP BY users
- Use AVG() to find the average of cookies across the table

```SQL
WITH count_cte AS(
    SELECT
        user_id,
        COUNT(cookie_id) AS cookie_count
    FROM users
    GROUP BY user_id
)
SELECT
    ROUND(AVG(cookie_count)) AS avg_cookie
FROM count_cte;
```

**3. What is the unique number of visits by all users per month?**
- Use TO_CHAR() to extract the names of every month in `start_date` 
- COUNT() every unique visit for every month

```SQL
SELECT
    TO_CHAR(u.start_date, 'MM - Month') AS month,
    COUNT(DISTINCT e.visit_id) AS visit_count
FROM users u
INNER JOIN events e
    ON u.cookie_id = e.cookie_id
GROUP BY month
ORDER BY month;
```

**4. What is the number of events for each event type?**
- Create a CTE that counts the number of rows per `event_type` and provides the name for each event

```SQL
With name_cte AS(
    SELECT
        i.event_name,
        e.event_type,
        COUNT(*) as event_count
    FROM events e
    INNER JOIN event_identifier i
        ON e.event_type = i.event_type
    GROUP BY e.event_type, i.event_name
)
SELECT 
    event_name,
    event_count
FROM name_cte
ORDER BY event_type;
```

**5. What is the percentage of visits which have a purchase event?**
- Use SUM() + CASE to count the number of a specific event such as purchase and COUNT() to count the number of unique visits
- Calculate the percentage by dividing the count of purchase events by the unique number of visits multiplied by 100.0

```SQL
SELECT
    ROUND(SUM(CASE WHEN event_type = 3 THEN 1 END ) * 100.0 / COUNT(DISTINCT (visit_id)),2) AS purchase_pct
FROM events
```

**6. What is the percentage of visits which view the checkout page but do not have a purchase event?**
- Use MAX() + CASE to act as a yes/ no flag, returning 1 if a row meets the condition and NULL if not. Set one MAX() + CASE for every Page View event on the Checkout Page as the checkout count and another for Purchase event as the purchase count
- Use SUM() on both purchase and checkout counts, then divide, subtracting 1 from the equation to flip purchases into didn't purchase
- Use 1.0 to convert INT into a decimal
  
```SQL
WITH pct_cte AS(
    SELECT
        visit_id,
        MAX(CASE WHEN page_id = 12 AND event_type = 1 THEN 1 END) AS checkout_count,
        MAX(CASE WHEN event_type = 3 THEN 1 END) AS purchase_count
    FROM events
    GROUP BY visit_id
)
SELECT
    ROUND(100.0 * (1 - (SUM(purchase_count) * 1.0/ SUM(checkout_count))), 2) AS pct
FROM pct_cte;
```

**7. What are the top 3 pages by number of views?**
- COUNT() the number of page IDs in `events` and JOIN with `page_hierarchy` to attach the name for each page ID
- GROUP BY the page name and ORDER BY the page count in descending order so that the highest count is at the top
- LIMIT to the top 3

```SQL
SELECT
    p.page_name,
    COUNT(e.page_id) AS page_count
FROM page_hierarchy p
INNER JOIN events e
    ON p.page_id = e.page_id
GROUP BY p.page_name
ORDER BY page_count DESC
LIMIT 3;
```

**8. What is the number of views and cart adds for each product category?**
- Use SUM() + CASE to count every View event and another SUM() + CASE for every Add to Cart event
- GROUP BY product category and filter results to not contain any NULL
  
```SQL
SELECT
    p.product_category,
    SUM(CASE WHEN e.event_type = 1 THEN 1 END) AS view_count,
    SUM(CASE WHEN e.event_type = 2 THEN 1 END) AS add_count
FROM events e
INNER JOIN page_hierarchy p
    ON e.page_id = p.page_id
WHERE p.product_category IS NOT NULL
GROUP BY p.product_category;
```

**9. What are the top 3 products by purchases?**
- Use a CASE to add a name for every `product_id` that is not NULL and COUNT() all rows as purchase count
- Filter results so event type is Add to Cart AND the `visit_id` is any purchase visits
- GROUP BY `product_id` and `page_name`, ORDER BY `purchase_count` in descending order so that the top purchases are at the top and then LIMIT to the top 3

```SQL
SELECT
    (CASE WHEN p.product_id IS NOT NULL THEN p.page_name END) AS product_name,
    COUNT(*) AS purchase_count
FROM events e
INNER JOIN page_hierarchy p 
    ON e.page_id = p.page_id
WHERE e.event_type = 2
  AND e.visit_id IN (
    SELECT visit_id
    FROM events 
    WHERE event_type = 3
)
GROUP BY p.product_id, p.page_name
ORDER BY purchase_count DESC
LIMIT 3;
```
