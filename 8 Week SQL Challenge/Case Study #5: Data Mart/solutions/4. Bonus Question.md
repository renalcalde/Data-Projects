To answer this question, we must do the following steps:

1. Use the GROUPING() function to return the `region`, `platform`, `age_band`, `demographic`, and `customer_type` columns into a single column

```SQL
SELECT 
    CASE 
      WHEN GROUPING(region) = 0 THEN 'region'
      WHEN GROUPING(platform) = 0 THEN 'platform'
      WHEN GROUPING(age_band) = 0 THEN 'age_band'
      WHEN GROUPING(demographic) = 0 THEN 'demographic'
      WHEN GROUPING(customer_type) = 0 THEN 'customer_type'
    END AS category
FROM clean_weekly_sales
GROUP BY GROUPING SETS (
    (region),
    (platform),
    (age_band),
    (demographic),
    (customer_type)
)
```

2. Use COALESCE() to return the subcategory for each category

```SQL
SELECT 
    CASE 
      WHEN GROUPING(region) = 0 THEN 'region'
      WHEN GROUPING(platform) = 0 THEN 'platform'
      WHEN GROUPING(age_band) = 0 THEN 'age_band'
      WHEN GROUPING(demographic) = 0 THEN 'demographic'
      WHEN GROUPING(customer_type) = 0 THEN 'customer_type'
    END AS category,
    COALESCE(region, platform, age_band, demographic, customer_type) AS subcategory
FROM clean_weekly_sales
GROUP BY GROUPING SETS (
    (region),
    (platform),
    (age_band),
    (demographic),
    (customer_type)
)
```

3. Using the same logic as Part 3, use BETWEEN..AND... with an +/- INTERVAL '12 weeks' to count from the baseline date 12 weeks before and after

```SQL
WITH sales_cte AS (
  SELECT 
    CASE 
      WHEN GROUPING(region) = 0 THEN 'region'
      WHEN GROUPING(platform) = 0 THEN 'platform'
      WHEN GROUPING(age_band) = 0 THEN 'age_band'
      WHEN GROUPING(demographic) = 0 THEN 'demographic'
      WHEN GROUPING(customer_type) = 0 THEN 'customer_type'
    END AS category,
    COALESCE(region, platform, age_band, demographic, customer_type) AS subcategory,
    SUM(CASE 
        WHEN TO_CHAR(week_date, 'MM-DD') BETWEEN 
             TO_CHAR(DATE '2020-06-15' - INTERVAL '12 weeks', 'MM-DD') 
         AND TO_CHAR(DATE '2020-06-15' - INTERVAL '1 day', 'MM-DD') 
         THEN sales ELSE 0 
    END) AS sales_before,
    SUM(CASE 
      WHEN TO_CHAR(week_date, 'MM-DD') BETWEEN 
           TO_CHAR(DATE '2020-06-15', 'MM-DD') 
       AND TO_CHAR(DATE '2020-06-15' + INTERVAL '12 weeks', 'MM-DD') 
       THEN sales ELSE 0 
    END) AS sales_after
  FROM clean_weekly_sales
  GROUP BY GROUPING SETS (
    (region),
    (platform),
    (age_band),
    (demographic),
    (customer_type)
  )
)
SELECT 
  category,
  subcategory,
  sales_before,
  sales_after
FROM sales_cte
```

4. Calculate and ORDER BY the growth rate in ascending order so that the highest negative values are at top

```SQL
WITH sales_cte AS (
  SELECT 
    CASE 
      WHEN GROUPING(region) = 0 THEN 'region'
      WHEN GROUPING(platform) = 0 THEN 'platform'
      WHEN GROUPING(age_band) = 0 THEN 'age_band'
      WHEN GROUPING(demographic) = 0 THEN 'demographic'
      WHEN GROUPING(customer_type) = 0 THEN 'customer_type'
    END AS category,
    COALESCE(region, platform, age_band, demographic, customer_type) AS subcategory,
    SUM(CASE 
        WHEN TO_CHAR(week_date, 'MM-DD') BETWEEN 
             TO_CHAR(DATE '2020-06-15' - INTERVAL '12 weeks', 'MM-DD') 
         AND TO_CHAR(DATE '2020-06-15' - INTERVAL '1 day', 'MM-DD') 
         THEN sales ELSE 0 
    END) AS sales_before,
    SUM(CASE 
      WHEN TO_CHAR(week_date, 'MM-DD') BETWEEN 
           TO_CHAR(DATE '2020-06-15', 'MM-DD') 
       AND TO_CHAR(DATE '2020-06-15' + INTERVAL '12 weeks', 'MM-DD') 
       THEN sales ELSE 0 
    END) AS sales_after
  FROM clean_weekly_sales
  GROUP BY GROUPING SETS (
    (region),
    (platform),
    (age_band),
    (demographic),
    (customer_type)
  )
)
SELECT 
  category,
  subcategory,
  sales_before,
  sales_after,
  ROUND((sales_after - sales_before) * 100.0 / NULLIF(sales_before, 0), 2) AS growth_rate
FROM sales_cte
ORDER BY growth_rate;
```
