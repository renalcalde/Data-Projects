
# 1. Data Cleansing Steps

In a single query, perform the following operations and generate a new table in the `data_mart` schema named `clean_weekly_sales`:
- Convert the `week_date` to a `DATE` format
- Add a `week_number` as the second column for each `week_date` value, for example any value from the 1st of January to 7th of January will be 1, 8th to 14th will be 2 etc
- Add a `month_number` with the calendar month for each `week_date` value as the 3rd column
 -Add a `calendar_year` column as the 4th column containing either 2018, 2019 or 2020 values
- Add a new column called `age_band` after the original `segment` column using the following mapping on the number inside the `segment` value

<div align="center">
  
| segment | age_band |
| ------- | -------- |
| 1 | Young Adults |
| 2 | Middle Aged |
| 3 or 4 | Retirees |

</div>

- Add a new `demographic` column using the following mapping for the first letter in the `segment` values:

<div align="center">

| segment | demographic |
| ------- | -------- |
| C | Couples |
| F | Families |

</div>

- Ensure all `null` string values with an `"unknown"`string value in the original `segment` column as well as the new `age_band` and `demographic` columns
- Generate a new `avg_transaction` column as the sales value divided by `transactions` rounded to 2 decimal places for each record

<br>

Before creating the `clean_weekly_sales`, we must complete the following steps:

1. Convert the `week_date` into the proper data type using the TO_DATE() function which also properly displays the dates into 'YYYY/MM/DD' format

```SQL
SELECT 
    TO_DATE(week_date, 'DD/MM/YY') AS week_date,
FROM weekly_sales;
```

2. Add a second column called  `week_number` that assigns the number of week for each unique `week_date`
   - Use MIN() to find the earliest date and convert it into the proper data type using TO_DATE()
   - Create a week bucket by subtracting the `week_date` from the minimum date and dividing it by 7, then use FLOOR() to get the largest value into a single INT
   - Add 1 to every week bucket to return the week number

```SQL
WITH date_bounds AS(
    SELECT MIN(TO_DATE(week_date, 'DD/MM/YY')) AS min_date
    FROM weekly_sales
),
bucketed AS(
    SELECT
        TO_DATE(w.week_date, 'DD/MM/YY') AS clean_week,
        FLOOR((TO_DATE(w.week_date, 'DD/MM/YY') - b.min_date) / 7)::INT AS week_bucket,
        b.min_date,
        w.region,
        w.platform,
        w.segment,
        w.customer_type,
        w.transactions,
        w.sales
    FROM weekly_sales w
    CROSS JOIN date_bounds b
)
SELECT
    clean_week AS week_date,
    week_bucket + 1 AS week_number,
    region,
    platform,
    segment,
    customer_type,
    transactions,
    sales
FROM bucketed
ORDER BY clean_week;
```

3. Add a `month_number` column by using EXTRACT() to get the month from the `clean_week` table and converting it into an INT data type
4. Apply the same logic for the next additional column, `calendar_year` and swap out the month for year

```SQL
WITH date_bounds AS(
```

5. Add two new columns, `demographic` and `age_band` after the original `segment` column using the tables (found above) to map the letters and numbers in `segment`
   - Use CASE with a LEFT() function to extract the characters from very the beginning of a string. Since the first characters of `segment` is letters, this would be the `demographic` column
   - Use another CASE with a SUBSTRING() function for the second position rather than a RIGHT() function since I don't know exactly if there's a predictable character count. Since the second characters of `segment` is numbers, this would be the `age_band` column

```SQL
WITH date_bounds AS(
    SELECT MIN(TO_DATE(week_date, 'DD/MM/YY')) AS min_date
    FROM weekly_sales
),
bucketed AS(
    SELECT
        TO_DATE(w.week_date, 'DD/MM/YY') AS clean_week,
        FLOOR((TO_DATE(w.week_date, 'DD/MM/YY') - b.min_date) / 7)::INT AS week_bucket,
        b.min_date,
        w.region,
        w.platform,
        w.segment,
        CASE LEFT(w.segment, 1)
            WHEN 'C' THEN 'Couples'
            WHEN 'F' THEN 'Families'
            ELSE NULL
        END AS demographic,
        CASE SUBSTRING(w.segment FROM 2)
            WHEN '1' THEN 'Young Adults'
            WHEN '2' THEN 'Middle Aged'
            WHEN '3' THEN 'Retirees'
            WHEN '4' THEN 'Retirees'
            ELSE NULL
        END AS age_band,
        w.customer_type,
        w.transactions,
        w.sales
    FROM weekly_sales w
    CROSS JOIN date_bounds b
)
SELECT
	  clean_week AS week_date,
    week_bucket + 1 AS week_number,
    EXTRACT(MONTH FROM clean_week)::INT AS month_number,
    EXTRACT(YEAR FROM clean_week)::INT AS calendar_number,
	  region,
    platform,
    segment,
    age_band,
    demographic,
    customer_type,
    transactions,
    sales

ORDER BY clean_week;
```

6. Turn all NULLs into an 'unknown' string value in the `segment`, `age_band` and `demographic` columns
   - Since 'null' in `segment` is a string rather than a true NULL, I had to trim and use NULLIF to turn any empty strings or 'null' strings into a NULL which I then convert into an 'unknown' string

```SQL
WITH date_bounds AS(
    SELECT MIN(TO_DATE(week_date, 'DD/MM/YY')) AS min_date
    FROM weekly_sales
),
bucketed AS(
    SELECT
        TO_DATE(w.week_date, 'DD/MM/YY') AS clean_week,
        FLOOR((TO_DATE(w.week_date, 'DD/MM/YY') - b.min_date) / 7)::INT AS week_bucket,
        b.min_date,
        w.region,
        w.platform,
        COALESCE(NULLIF(NULLIF(TRIM(w.segment),''), 'null'), 'unknown') AS segment,
        CASE LEFT(w.segment, 1)
            WHEN 'C' THEN 'Couples'
            WHEN 'F' THEN 'Families'
            ELSE 'unknown'
        END AS demographic,
        CASE SUBSTRING(w.segment FROM 2)
            WHEN '1' THEN 'Young Adults'
            WHEN '2' THEN 'Middle Aged'
            WHEN '3' THEN 'Retirees'
            WHEN '4' THEN 'Retirees'
            ELSE 'unknown'
        END AS age_band,
        w.customer_type,
        w.transactions,
        w.sales
    FROM weekly_sales w
    CROSS JOIN date_bounds b
)
SELECT
	  clean_week AS week_date,
```
